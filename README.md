# Chapter7

This repository contains Java source code related to "Chapter7".

Language: Java (100%)

## Requirements

- Java Development Kit (JDK) 11 or newer

## Build

Compile all Java files (example):

```bash
javac -d out $(find . -name "*.java")
```

If the project uses a build tool (Maven/Gradle), prefer those commands instead:

- Maven: `mvn clean package`
- Gradle: `./gradlew build`

## Run

Run the compiled classes (example):

```bash
java -cp out <MainClass>
```

Replace `<MainClass>` with the fully-qualified class name that contains `public static void main(String[] args)`.
